# Практична робота: Документування JAVA-програм

Цей проєкт присвячений вивченню стандартів документування коду в Java за допомогою Javadoc. У рамках роботи була створена ієрархія класів для моделювання структури компанії та згенерована веб-документація.

## 🛠 Опис проєкту
Проєкт містить пакет `domain`, який моделює структуру співробітників:
* `Employee` — базовий клас.
* `Manager` — управління підлеглими.
* `Artist` — творчі фахівці та їхні нащадки (`Editor`, `GraphicIllustrator`, `TechnicalWriter`).
